Currere — Rules

Goal

Run your tiles off the enemy's back edge. Each tile = 1 point. First to 6 wins. Tie: most points → most tiles alive → second player.

Units

Type is permanent. Tiles can never be un-stacked.

Actions (one per turn — never pass)

Move through empty hexes. Combine adjacent friendlies (max 3). Attack adjacent enemy. Detonate (fighter): destroy it + all 6 neighbors. Attacker stays put.
